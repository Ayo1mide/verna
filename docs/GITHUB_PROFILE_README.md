## Featured Project: Verna

**Verna** is an anonymous poem-sharing platform where users can post poems,
reply to poems with poems, save, repost, follow anonymous poetic identities, and
use AI to turn raw thoughts into editable poems before publishing.

What it demonstrates:

- Custom Google OAuth flow with app-issued JWTs.
- Anonymous-but-stable public identity such as `verna1`, `verna2`, `verna100`.
- Supabase/PostgreSQL schema for feeds, profiles, replies, reposts, saves,
  follows, reactions, reports, and moderation.
- AI-assisted poem generation/editing before posting.
- Frontend deployed with Vite/React and backend Edge Functions.
- Product and research thinking around anonymity, social computing, and creative
  expression.

Repository: `Ayo1mide/verna`
